## 📋 Project Analysis

### 1. User Profile (User Persona)
* **Name / Target Profile:** Hiring managers, tech recruiters, and engineering leads in the United States looking for junior full-stack developers.
* **Needs & Expectations:** They want to quickly review a candidate's work history, core technical stack, education, and portfolio projects without navigating through multiple pages. They value clean design, fast loading times, clear contact information, and professional English writing.

### 2. Information Architecture
For this project, I decided to build a single-page layout because it is very easy for recruiters to read everything quickly without clicking on multiple pages. All the important information is organized vertically from top to bottom in a logical order. First, at the very top, there is the header section. This part includes my profile picture, my full name (Alejandro García), my job title, and quick contact links like email, LinkedIn, and GitHub. Right below the header, visitors can read the "About Me" section, which gives a short summary of who I am and my career goals. Following this, I placed the "Experience" section because work history is usually the most important thing for hiring managers. After experience, I put "Education", followed by "Technical Skills" and "Soft Skills" so people can see my technical and personal abilities clearly. Next, I added a "Languages" section. Further down, there is a "Featured Projects" section where visitors can click on real web apps and projects I have worked on. Finally, at the bottom of the page, there is "Additional Information" about my availability and relocation, and a simple footer. This structure helps users find everything they need in one single place smoothly.

### 3. Visual Design
When planning the visual design of my CV website, I wanted to keep it clean, professional, and easy to read, especially because it is targeted at the US market. For the color palette, I chose a dark blue color for the main header background because it looks serious and professional. The rest of the page uses a clean white background with dark gray text to ensure high contrast and good readability on any screen. For the typography, I used standard web fonts like sans-serif to keep the page modern and fast. The page layout is designed as a single-column A4 paper format. I chose this layout because it looks like a traditional printed CV, which makes it very familiar and comfortable for recruiters to review quickly. I decided not to use heavy CSS frameworks like Bootstrap because a simple, custom CSS file is enough to style this layout, and it helps the website load much faster. I also used Figma to create a prototype first, making sure the design was well-organized before writing the HTML and CSS code. Overall, the design focuses on simplicity, good spacing, and a professional look without unnecessary distractions.
